## Неочевидные решения этой сессии (ПОЧЕМУ)

- **Общие вопросы визуально скопировали с «Вопросы для проверки»**, а не сделали «богатый» список: во время живого интервью важна узнаваемость и минимум кликов; edit/reorder сознательно выкинули, чтобы не разъезжались две колонки.
- **Нумерация через те же `check-num` / `check-text`**, а не отдельный компонент: один визуальный язык; после добавления нумерации нельзя оставлять `display: block` у пункта — иначе сетка номера ломается (нужен тот же grid, что у check-list).
- **Шрифт общих вопросов принудительно `0.88rem`**, потому что у `.general-list .check-text` раньше стоял override `1rem` / `font-weight: 500` — без снятия override «как в правой колонке» не получалось.
- **Зазор под заголовком сжат специально** (`margin`/`padding` у head/body и `padding-top: 0` у первого пункта): пользователь явно просил «вопросы точно под заголовком».
- **Дефолтные 12 вопросов сидятся только если `generalQuestions` нет или пустой**: чтобы не затирать уже накопленный экспертный список в LocalStorage при каждом заходе.

## Ловушки / грабли для следующей сессии

- **Cursor Git: `Bad status code: 500`** — кнопка Commit в IDE часто падает; `git` в PowerShell работает. Не тратить время на «починку Cursor» без запроса; коммитить так:
  ```powershell
  cd C:\Work\ProfZOR
  git status
  git add .
  git commit -m "…"
  git push
  ```
- **Кэш CSS/JS**: после правок стилей пользователь должен делать `Ctrl+F5`, иначе кажется, что «не применилось».
- **Ключи LocalStorage**: интервью — `profzor_last_interview_v2`, черновик сырых заметок — `profzor_raw_draft_v1`. Старый `v1` / непустой кастомный `generalQuestions` — частая причина «не вижу 12 дефолтов».
- **Клик по радикалу** в центре: текущие сырые заметки уходят в наблюдения выбранного радикала, поле очищается, фокус снова в заметки — это задумано; не «чинить» как потерю текста без согласования с пользователем.
- **Язык общения и коммитов — русский**; примеры команд — только **PowerShell** (не bash).
- Handoff-файл новый: до этой сессии `docs/handoff/` в репо не было — при желании закоммитить отдельно.
